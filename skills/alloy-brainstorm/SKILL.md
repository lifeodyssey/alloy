# Alloy Brainstorm

Use this before implementing new behavior, architecture, UI, workflow, or substantial refactors.

## Process

1. Explore current project context before asking questions.
2. Separate discoverable facts from product preferences.
3. Ask only questions that materially change the design.
4. Propose 2-3 approaches with tradeoffs.
5. Recommend one approach and explain why.
6. Convert the chosen approach into a decision-complete plan before implementation.

## Design Checklist

- Goal and success criteria.
- Audience and workflow.
- In scope and out of scope.
- Interfaces, inputs, outputs, and generated artifacts.
- Data flow and ownership boundaries.
- Failure modes and rollback.
- Test and verification plan.

Do not start implementation while high-impact choices remain unsettled.
